Install Alogi on CachyOS & Ubuntu

Choose a fast portable AppImage, a native Ubuntu deb, or a pacman package for Arch-based systems. All builds are signed and published on GitHub Releases.

Latest Release AppImage Debian Pacman

AppImage (portable)

Works on most Linux distros, no root required.

# Download the AppImage from the latest release page
chmod +x Alogi-*.AppImage
./Alogi-*.AppImage

Grab the AppImage from the latest GitHub Release.

Ubuntu / Debian (.deb)

# Download the .deb from the latest release page
sudo apt install ./Alogi_*_amd64.deb

Tip: you can also install via your file manager.

Arch / CachyOS (pacman)

Use the PKGBUILD in the repo or publish to AUR for `yay -S alogi`.

git clone https://github.com/allisonhere/alogi.git
cd alogi
npm run dist:linux:dir

tar -C dist-electron -czf packaging/arch/linux-unpacked.tar.gz linux-unpacked
cd packaging/arch
makepkg -f
sudo pacman -U alogi-*.pkg.tar.zst
