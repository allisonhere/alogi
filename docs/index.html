Install Alogi

Download a prebuilt Linux package or build from source.

AppImage (portable)

Works on most Linux distros, no root required.

curl -L -o Alogi-x86_64.AppImage https://github.com/allisonhere/alogi/releases/latest/download/Alogi-x86_64.AppImage
chmod +x Alogi-x86_64.AppImage
./Alogi-x86_64.AppImage
Download AppImage

Ubuntu / Debian (.deb)

Native package for Ubuntu and Debian-based systems.

curl -L -o Alogi-amd64.deb https://github.com/allisonhere/alogi/releases/latest/download/Alogi-amd64.deb
sudo apt install ./Alogi-amd64.deb
Download .deb

Arch / CachyOS (pacman)

Install the prebuilt pacman package or build locally from the PKGBUILD.

curl -L -o alogi-arch.pkg.tar.zst https://github.com/allisonhere/alogi/releases/latest/download/alogi-arch.pkg.tar.zst
sudo pacman -U alogi-arch.pkg.tar.zst
